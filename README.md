# employee-performance-attrition-analysis
This project aims to analyse employee performance, job satisfaction, work-life balance and attrition trends using MySQL and Power BI. The project integrates employee, performance and attrition datasets into a centralized data warehouse and presents key insights through interactive dashboards.
